## I build the lab, break it, then detect it.

I'm **Hafidh**, a cybersecurity and software engineering student based in **Luxembourg**, studying at **42 Luxembourg** and the **DLH Cybersecurity Academy** (SOC Analyst / Penetration Testing track).

I learn security by deploying the tools and attacking my own environment. My home SOC runs **OPNsense, Wazuh, Graylog and LibreNMS** around an Active Directory domain, and I use it to turn raw telemetry into alerts, investigations and written reports.

My current focus is **security monitoring and incident response**, backed by hands-on Blue Team projects, Fortinet training (NSE 1 and 2 completed) and a Microsoft security learning path.
